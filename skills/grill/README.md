# grill

Has Claude interrogate you about a project until the weak spots show. Run `/grill <project>` or say "poke holes in this," and Claude asks a few pointed questions per round about scope, stack, constraints, failure modes, maintenance, and whether it's worth doing. It pushes on vague answers and calls out contradictions.

Ends with a summary of pros, cons, risks, open questions, and a straight verdict. Chat only, no files.
